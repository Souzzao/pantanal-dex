# PantanalDex MVP — início rápido

Requisitos: Node.js, pnpm e ambiente Expo compatível.

```bash
pnpm install
pnpm check
pnpm test
pnpm dev
```

O comando `pnpm dev` inicia o servidor e o Metro web. Para uma exportação web estática, use:

```bash
npx expo export --platform web --output-dir dist-web
```
